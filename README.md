# Мини-графический редактор

## 1. Название и описание задачи

Учебный проект на Python, который показывает три принципа ООП на примере
графических фигур. Программа создаёт список из пяти фигур (круги и квадраты),
считает площадь каждой в одном цикле и выводит общую площадь.

## 2. Архитектура проекта

**Инкапсуляция.** Базовый класс `Figure` хранит координаты в скрытых
атрибутах `_x` и `_y`. Напрямую к ним обращаться не нужно, доступ идёт
только через публичные методы `get_coords()` и `set_coords(x, y)`.

**Наследование.** Классы `Circle` и `Square` наследуются от `Figure`.
Координаты и методы доступа к ним они получают от родителя через
`super().__init__()`. Каждый класс добавляет своё свойство: `radius`
у круга и `side` у квадрата.

```
Figure
├── Circle
└── Square
```

**Полиморфизм.** В `Circle` и `Square` переопределён метод `calculate_area()`.
Фигуры лежат в одном списке, и в цикле для каждой вызывается один и тот же
метод. Нужная версия выбирается автоматически по типу объекта. Новый тип
фигуры можно добавить, не меняя код цикла.

## 3. Пример использования

```python
figures = [
    Circle(10, 20, 5),
    Square(30, 40, 4),
    Circle(50, 60, 3),
]

total_area = 0
for figure in figures:
    total_area += figure.calculate_area()

print("Общая площадь всех фигур:", total_area)

figures[0].set_coords(0, 0)
print(figures[0].get_coords())
```
